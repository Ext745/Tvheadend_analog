# Decision Records

One short file per significant decision: `NNNN-short-title.md`, numbered in order. Copy `0000-template.md`.

Write one when:
- the project changes direction
- an unconventional approach is chosen over the obvious one
- an option is rejected that someone (or some agent) might later try to "fix" back

Decisions aren't deleted. If one is reversed, write a new record that supersedes it.
